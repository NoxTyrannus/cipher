判断被淘汰的注意力条目中是否含有用户偏好信息。系统会同时提供被淘汰条目对应的原始对话证据，用于查证。

输入:
- 被淘汰的注意力条目列表（focus + 淘汰原因）
- 原始证据（按 focus 分组，含原始输入和输出）

产出:
- 偏好文档（用户习惯、默认选择、明确表达的喜欢/不喜欢），或“无值得提取的内容”。
- 输出 JSON 数组，每条偏好含 "key" 和 "value" 字段。

提取标准:
- 用户说“我喜欢/不喜欢/习惯/偏好 X” → 提取
- 用户反复使用同一工具/语言/方法 → 提取为偏好
- 用户明确设置默认值（“以后都用 X”）→ 提取
- 纯临时需求（“这次用 X”）→ 不提取
- 用户更正 agent 的行为（“不对，应该用 Y”）→ 提取为偏好（“用户倾向于 Y”）

查证要求:
- 先对照原始证据，确认偏好确实是用户表达，而不是 agent 自己的推测。
- 每条偏好必须能追溯到原始证据。
- 无证据支持时输出 []。

偏好格式: 每条偏好含“偏好类型/具体内容/来源轮次”，不超过 100 字。
