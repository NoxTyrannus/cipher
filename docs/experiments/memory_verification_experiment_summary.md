# D12 经验/偏好查证实验摘要

## 设计
- 8 个合成场景（4 经验 + 4 偏好），每条注意力含 source_refs。
- 真实 MiniMax-M3，每个场景 × 2 轮 × 3 方案。
- 评分：recall/precision 对黄金事实确定性比对；可靠性=parse_ok；速度=latency/tokens。

## 结果
| 方案 | recall | precision | parse_ok | 平均 tokens | 平均耗时 ms |
|---|---|---|---|---|---|
| A 输入前准备 | 0.75 | 1.00 | 1.00 | 605 | 1982 |
| B agent 自查 | 0.50 | 0.6875 | 0.9375 | 680 | 9147 |
| Hybrid | 0.6875 | 1.00 | 1.00 | 652 | 1616 |

## 决策
可靠性优先，其次质量，再次速度：**采用 A（输入前准备）**。
- 系统按 source_refs 预取原始证据，经验/偏好 agent 单轮提取，写入能力通道。
- B 保留为后续工具协议成熟后的可选增强方向。
